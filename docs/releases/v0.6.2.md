# v0.6.2

## SafeNet Fusion container cleanup

On devices identified as SafeNet Fusion by their PC/SC reader name,
`InitializeToken` with `ClearContainers: true` now uses the same slot `9E`
cleanup as a full PIV reset. The adapter clears the key container `FF900E`
and public mirror `FFF301` even when the card omits those tags from discovery.
Initialization reports the three writes. A rejected write stops the remaining
container cleanup and returns the card error.

Goodkey App can adopt this version for its managed `piv_reset` task, which
requests container cleanup through `InitializeToken`. The application can
rotate credentials in its subsequent lifecycle steps. [Pull request #28](https://github.com/PeculiarVentures/piv-go/pull/28)
